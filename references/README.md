# References

This bibliography follows the official material for the University of Trieste
Probabilistic Machine Learning course and adds the papers required for the
SVGD–EBM project.

## Official course material

- Luca Bortolussi, *Probabilistic Machine Learning — Lecture Notes*, University
  of Trieste, 2024. [Course notes](https://moodle2.units.it/pluginfile.php/757635/mod_resource/content/3/PML_notes.pdf)
- [Probabilistic Machine Learning course page](https://moodle2.units.it/course/view.php?id=15208&lang=en)
- [Official course syllabus](https://degree.units.it/en/0320107313600001/students-area/taught-courses/2025/119904/2025/1/10681/2025/13044)

The most relevant parts of the course notes for this project are sampling-based
inference and MCMC (Chapter 8), variational inference (Chapter 10), generative and
score-based diffusion models (Chapter 11), and kernel methods (Chapter 12).

## Course-project requirements

According to the public course page, the group project must cover a method related
to probabilistic machine learning and generative AI, include an implementation and
experimental test, and be presented in at most ten minutes followed by questions.
The intended audience is the rest of the class, so standard course material should
not be explained at length.

## Distribution note

This repository stores citations and links only. Course files and textbook PDFs
must be accessed through their official pages and must not be redistributed here.
