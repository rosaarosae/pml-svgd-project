# Sources

## Primary reference

Qiang Liu and Dilin Wang, **“Stein Variational Gradient Descent: A General Purpose
Bayesian Inference Algorithm,”** NeurIPS 2016.

- [NeurIPS proceedings](https://proceedings.neurips.cc/paper/2016/hash/b3ba8f1bee1238a2f37603d90b58898d-Abstract.html)
- [arXiv](https://arxiv.org/abs/1608.04471)
- [HTML version](https://arxiv.org/html/1608.04471v3)

The SVGD update is introduced in Section 3.2. The Gaussian mixture and Bayesian
neural network examples appear in Sections 5.1 and 5.3.

## Reference implementation

- [DartML/Stein-Variational-Gradient-Descent](https://github.com/DartML/Stein-Variational-Gradient-Descent)

The original repository contains Python and MATLAB demonstrations. Its Bayesian
neural network example uses Theano, so it is best treated as historical reference
code rather than a modern dependency.
